# 催缴函模板集

---

## 模板一：首次催缴函（逾期7-15天）

```
                                 催 缴 通 知 函

致：[租户公司全称]

关于：[项目名称][房号]房屋租赁费用催缴事宜

贵司与我司于[签约日期]签署《房屋租赁合同》（合同编号：[合同号]），约定贵司承租
[项目名称][房号]，租赁面积[面积]㎡。

根据合同约定，贵司应于每月[付款日]前支付当月租金及物业费。截至本函发出之日，
贵司尚欠以下费用：

┌─────────────────────────────────────────────┐
│ 欠费项目        期间            金额（元）     │
├─────────────────────────────────────────────┤
│ 租金            [月份]          [金额]        │
│ 物业费          [月份]          [金额]        │
│ 滞纳金          —               [金额]        │
├─────────────────────────────────────────────┤
│ 合计                            [总金额]      │
└─────────────────────────────────────────────┘

请贵司于[最后期限]前将上述款项支付至以下账户：
  户名：[收款账户名称]
  账号：[银行账号]
  开户行：[开户行名称]

如逾期仍未支付，我司将依据合同第[X]条约定，计收每日[比例]的违约金，并保留
采取进一步法律措施（包括但不限于解除合同、提起诉讼）的权利。

如有疑问，请联系：[联系人][电话]

                                              [出租方公司名称]（盖章）
                                              [日期]

────────────────────────────────────────
签收：
签收人：_______________  日期：_______________
```

## 模板二：严重催缴函（逾期15-30天）

```
                            严 重 催 缴 通 知 函

致：[租户公司全称]

关于：[项目名称][房号]房屋租赁费用严重逾期催缴事宜

贵司承租我司[项目名称][房号]（合同编号：[合同号]），截至本函发出之日，
已累计拖欠租金及物业费达[天数]天，金额合计[总金额]元（详见明细）。

我司已于[日期]向贵司发送首次催缴通知，但至今未收到款项。

现郑重通知贵司：

1. 请于[最后期限]前付清全部欠款，否则滞纳金将按[比例]继续累计；
2. 如贵司未在上述期限内付清，我司将根据合同第[X]条约定及《民法典》相关规定，
   启动合同解除程序，并要求贵司腾退房屋、承担全部违约责任；
3. 由此产生的诉讼费、律师费、保全费等全部由贵司承担。

我们希望贵司能够重视此事，避免问题升级。

如有特殊情况，请于[日期]前联系[联系人][电话]进行协商。

                                              [出租方公司名称]（盖章）
                                              [日期]

────────────────────────────────────────
签收（EMS快递单号：[单号]）：
签收人：_______________  日期：_______________
```

## 模板三：停水停电告知函（逾期60天+）

```
                            停 止 服 务 通 知 函

致：[租户公司全称]

关于：[项目名称][房号]停止物业服务事宜的通知

贵司承租我司[项目名称][房号]（合同编号：[合同号]），截至本函发出之日，
已累计拖欠租金及物业费[总金额]元，逾期[天数]天。

我司已先后于[日期]、[日期]发送催缴通知函，但贵司均未履行付款义务。

根据合同第[X]条约定："承租方逾期支付租金超过[X]日的，出租方有权采取
包括但不限于停止供水、供电等强制措施，因此造成的一切损失由承租方承担。"

现我司正式通知贵司：将于[日期]起停止对[房号]的供水、供电服务。
请贵司在此前做好相关准备，并尽快缴清欠款以恢复服务。

如有异议，请于[日期]前联系[联系人][电话]。

                                              [出租方公司名称]（盖章）
                                              [日期]

────────────────────────────────────────
签收：
签收人：_______________  日期：_______________
```

> ⚠️ 使用前请咨询专业律师确认停水停电条款在当地的司法实践中是否被支持。
