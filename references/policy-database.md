## 三、申报流程标准SOP

```
政策跟踪 → 条件比对 → 材料准备 → 线上申报 → 专家评审 → 公示 → 资金拨付 → 绩效评价
```

### 各环节要点
1. **政策跟踪**：建立政策日历，标记每个政策的申报窗口期
2. **条件比对**：逐条核对申报条件，差1条就不能报
3. **材料准备**：提前3个月开始准备，做好材料 check list
4. **线上申报**：注意系统开放时间，先草稿再正式提
5. **答辩准备**：PPT 控制在15页以内，突出亮点和量化指标
6. **资金拨付**：跟踪拨付进度，及时提供收款账户信息
7. **绩效评价**：拨付后按要求提交验收/绩效报告
