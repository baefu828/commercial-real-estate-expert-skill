# 商业地产招商策略手册

> 覆盖招商全流程，从渠道搭建到品牌落位到签约落地。基于10个月完成95%招商率的实战经验。

---

## 一、招商全流程

```
市场调研 → 项目定位 → 租金定价 → 渠道搭建 → 客户拓展 → 带看洽谈 → 
意向锁定 → 合同谈判 → 签约落地 → 进场装修 → 开业
```

## 二、渠道体系搭建

### 2.1 渠道矩阵

| 渠道类型 | 占比目标 | 具体来源 | 管理方式 |
|---------|---------|---------|---------|
| 中介渠道 | 40% | 链家/贝壳、戴德梁行、仲量联行、当地中小中介 | 合作协议+佣金+定期维护 |
| 线上平台 | 25% | 58同城、贝壳找房、点点租、好租 | 定期发布+及时回复 |
| 自拓直客 | 20% | 园区周边扫楼、行业协会、商会 | CRM跟进 |
| 老带新 | 10% | 已入驻租户推荐 | 推荐奖励机制 |
| 政府招商 | 5% | 投促局/招商局引荐 | 专人对接 |

### 2.2 中介合作机制

| 合作要素 | 设置建议 |
|---------|---------|
| 佣金标准 | 写字楼通常1-2个月租金，商铺1-1.5个月 |
| 佣金支付节点 | 签约+首笔租金到账后支付 |
| 保护期 | 带看后30天内成交算该中介 |
| 黑名单机制 | 防止中介截客/飞单 |
| 中介大会 | 季度举办，维护关系+发布空置信息 |

### 2.3 中介网络管理（已积累37家、170+经纪人）

| 分类 | 数量 | 维护频率 | 维护方式 |
|------|------|---------|---------|
| 核心中介（高频带看） | 10-15家 | 每周 | 专人对接、优先释放房源 |
| 活跃中介（有带看） | 15-20家 | 双周 | 微信群维护、房源更新 |
| 长尾中介（偶尔带看） | 50+家 | 月度 | 群发房源信息 |

## 四、招商漏斗管理

```
   触达客户 ───────────────── 100%
      ↓
   意向客户 ─────────────── 40-50%
      ↓
   带看客户 ─────────────── 25-30%
      ↓
   洽谈客户 ─────────────── 15-20%
      ↓
   发意向书 ─────────────── 10-12%
      ↓
   签约客户 ─────────────── 8-10%
```

### 各环节转化率标准
| 环节 | 健康值 | 预警值 | 提升手段 |
|------|--------|--------|---------|
| 触达→意向 | >40% | <25% | 优化渠道质量、调整价格策略 |
| 意向→带看 | >60% | <40% | 提升跟进速度、改善话术 |
| 带看→洽谈 | >50% | <30% | 提升带看专业度、匹配客户需求 |
| 洽谈→签约 | >50% | <30% | 商务条件灵活度、谈判技巧 |

## 五、招商去化节奏

| 阶段 | 时间 | 目标去化率 | 策略重点 |
|------|------|-----------|---------|
| 预热期 | 开业前8-6月 | 20-30% | 锁定标杆品牌+主力品牌 |

## 六、文三数字生活街区 0101PARK 招商实战

### 6.1 2025年招商KPI
| 指标 | 数据 |
|------|------|
| 年度去化面积 | **3,615㎡** |
| 整体出租率 | **95%** |
| 全年洽谈商家 | **500+** |
| 新签约品牌 | **17个**（不含协助玩美招商的5个） |
| 调整解约品牌 | 6个（受经济环境和前期调研不足影响） |
| 成功引入浙江首店 | 腾讯音乐、唱吧不是吧、执事咖啡、深空纪元、焱无罗和牛烤肉等 |

### 6.2 招商策略复盘
**亮点**：
- 明确功能定位→瞄准招商方向→积极参与展会/项目考察
- 创新全国首个黑神话线下门店+雄狮少年痛楼，制造市场话题
- 引入集装箱市集+B区露台改造，造集休闲社交/艺术人文/夜经济一体特色街区
- AB区情景融合、业态互补

### 6.3 暴露的问题与教训
1. **品牌落位签约前期调研不足**：
   - 对品牌适配度及运营团队评估不够深入（运营经验/产品特色/财务状况/客群匹配度）
   - 导致入驻后抗风险能力弱，提前撤场率较高
   - 二次招商成本增加+商业氛围连贯性受损
2. **2026年方向**：从"招满商"到"招好商、招强商"，强化前期研判与品牌适配度评估，以前期商户经营结果反向指导招商决策

### 6.4 2026年招商策略方向
- 优先聚焦五大领域：科技体验、潮流文创、新零售、数字娱乐、餐饮美食
- 结合街区业态规划与消费数据，明确各区域招商定位
- 强化品牌前置研判与精准筛选
- 积极探索创新合作模式，为优质品牌入驻创造条件
- 重点引入具有内容创造力、客流带动力和长期运营能力的优质品牌

### 8.3 总结：商户全周期管理核心经验
1. **新商户**：建立"一对一"对接机制，从场地交付→装修管控→证照办理全程跟进
2. **存量商户**：日常走访+电话沟通+专项约谈，收集诉求，帮扶方案（租金缓缴/联合营销/达人探店/霸王餐）
3. **问题商户**：妥善推进终止合作，高效完成场地清退/费用结算/资产移交闭环
4. **诉讼商户**：全程跟进（委托律师→补充资料→对接事务→仲裁裁决→申请执行）
5. **精细化运营不足**：工作时间碎片化→运营效率受限；深层经营指导（产品优化/经营策略/精准营销）有待加强
