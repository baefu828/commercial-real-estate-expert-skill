# 物业管理制度（西溪湿地标准）

> 基于「杭州西溪湿地旅游管理有限公司物业管理办法」（2023.10）及《西溪湿地物业管理规约》。
> 源自实际运营制度，适用于物业管理工作中的标准参考。

---

## 一、管理法律依据

- 中华人民共和国物业管理条例
- 省、市及杭州西溪湿地保护管理条例
- 工商、卫生、消防、城建等相关法律法规
- 租赁合同、西溪湿地物业管理规约

---

## 二、商户营业管理标准

### 2.1 证照要求
- 须持有**营业执照**，亮证经营
- 专营/专卖商品须持有**相应许可证**
- 按要求按时进行证照**年检**

### 2.2 经营合规
| 法规 | 要求 |
|------|------|
| 《产品质量法》《反不正当竞争法》 | 不出售假冒伪劣和"三无"商品 |
| 《消费者权益保护法》 | 承担"三包"（包修、包退、包换）责任 |
| 价格法律法规 | **明码标价**，不搞价外收费、虚假让利、价格欺诈 |
| 《计量法》 | 使用符合标准量器和衡器 |
| 预付卡 | 禁止在街区开展预付卡业务，如需开展须提前报备运营部 |

### 2.3 营业时间
- 执行0101PARK**统一营业时间**
- 未经批准不得擅自闭店或延迟营业

## 三、环境卫生标准（"门前三包"）

| 要求 | 具体标准 |
|------|---------|
| 店铺门前区 | 整洁干净，无垃圾杂物、丢弃物和明显污迹 |
| 门窗/地面/墙面 | 整洁明亮，无异味、飞虫、爬虫 |
| 垃圾管理 | 厚实黑色垃圾袋包装，无滴水渗漏，当日营业结束后放置指定清运点 |
| 餐饮排水沟 | **每日打扫** |
| 油污处理 | 须与专业公司签订合同定期清理 |
| 厨房烟囱烟道 | **按月清理**，做清洗记录 |
| 店面形象 | 禁止私自张贴广告或堆放杂物 |

---

## 四、安全消防管理

### 4.1 核心要求
- 遵守《消防法》及安全生产管理法律法规
- 签订租赁合同时**必须同时签订**《物业租赁安全管理责任书》
- 商户须**定期/不定期自查**，排除隐患

### 4.2 消防器材标准
- 每**100㎡配2只4kg干粉灭火器**
- 仓库、厨房**加倍**配置

### 4.3 安全检查与处罚

| 情形 | 处理 |
|------|------|
| 园区管理部门安全检查 | 有权随时进入物业检查，发现隐患开具**整改单** |
| 逾期不改/整改不到位 | 按安全责任书**处罚**，情节严重**解除合同** |
| 消防隐患首次未整改 | 扣保证金**2000元** |
| 消防隐患第二次未整改 | 追加扣**5000元** |
| 消防隐患第三次未整改 | **终止合同**，取消租赁资格 |

### 4.4 消防安全相关表单
- 《物业租赁安全管理责任书》
- 《装修期消防安全责任书》
- 《消防责任安全协议》
- 《安全承诺书》

## 五、车辆与货运管理

| 规则 | 内容 |
|------|------|
| 车辆出入 | 服从园区管理制度 |
| 货物配送/装修车辆 | 遵守吨位限制、车型、货物包装规定 |
| **货运车辆通行时间** | **7:30前**和**18:00后**，装卸货后立即离开 |
| 重大节日/接待活动 | 货运车辆**不得驶入** |

## 六、商户报修管理

- 房屋、公共设施等维修统一上报物业管理部
- **商户自行改建或改动过结构的物业不在维修范围内**
- 报修流程：商户报修 → 物业记录 → 派工维修 → 验收确认

## 十、0101PARK 运营管理制度 V1 补充（2026版）

> 来源：文三运营管理制度（V1）.docx

### 10.1 标识标牌管理
- 设置招牌/广告须提前书面报运营部审批
- 未经同意擅自设置/拒不维修损坏招牌，运营方可直接拆除并复原墙面，费用由承租方承担
- 商户使用街区相关标识须报运营部审批

### 10.2 客户服务与投诉处理
- **服务标准**：首问负责制、一站式解决
- **闭环流程**：登记→限期处置（一般投诉24小时办结）→回访确认→归档复盘
- 重复投诉/重大投诉直接纳入商户信用降级

### 10.3 处罚措施（制度原文）
| 违规情形 | 处罚 |
|---------|------|
| 违反制度/合同/法规/损害街区利益 | 开具整改单 |
| 每张整改单 | 扣除保证金**500元**（从保证金直接扣） |
| 累计8次整改单 | 公司有权**单方解除租赁关系** |
| 消防隐患未按期整改 | 责令停业整改，首次扣**2000元**，第二次**5000元**，第三次**终止合同** |
| 违规扩建/安全隐患拒改 | 实施**暂停物业服务**（暂停装修审批/证照办理/维修/宣传/活动参与等） |

### 10.4 应急管理与突发事件处置
- 成立应急处置小组，明确现场指挥/疏散引导/医疗救援/信息上报/后勤保障分工
- 专项应急预案8类：火灾、地震、极端天气、客流拥堵踩踏、设备故障（电力/电梯/供水）、食品安全事故、商户纠纷冲突、突发公共卫生事件
- **培训演练**：每半年≥1次综合/专项演练，每年≥2次应急知识培训（覆盖运营团队+商户+核心员工）
- 物资储备：灭火器、急救箱、疏散标志、应急照明、扩音器、录音笔等，定期检查更新
- 处置原则：**人员安全优先**→控制事态→外部联动（消防/公安/医疗）→善后处理

### 10.5 撤场/清退管理流程（V1制度版）
| 情形 | 流程 |
|------|------|
| 合同到期 | 期满前90日提交续租申请 → 未申请/未续租视为自动撤场 → 期满前30日提交《撤场申请书》 |
| 提前撤场/清退 | 运营部同步商户情况→招商部牵头→协商/发腾退通知函 |
| 账目清算 | 财务+运营核对欠费→形成《催款单》→足额缴纳后方可进入下一环节→保证金不足抵扣的启动法务诉讼 |
| 铺位恢复 | 按合同约定复原→依照《商铺回收确认表》验收→遗失/损坏扣保证金 |
| 强制清场 | 严重违约/失联/拒不配合→停止水电供应→封存铺内物品→全程录像→依法追究违约责任 |

### 10.6 一店一档管理
- 统一管理、**电子+纸质双存档**、按月整理、按年归档、可追溯可核查
- 文书档案：合同、协议、装修图纸、交房材料、制度、签批、记录、会议纪要、收发文、往来函件、计划、总结、考核、巡检、整改、奖惩、投诉
- 电子档案：图像、影像、声音、多媒体、数据

### 10.7 核心KPI指标
| 指标 | 目标值 | 备注 |
|------|-------|------|
| 租金收缴率 | ≥95% | 运营部核心指标 |
| 每日现场巡查 | ≥3次 | 重点消防安全+合规经营 |
| 投诉办结 | 一般24小时内 | 首问负责制 |
| 应急演练 | ≥1次/半年 | 综合或专项 |
| 应急培训 | ≥2次/年 | 覆盖全员 |
| 顾客满意度调研 | 每季度1次 | 持续优化消费体验 |
| 商户沟通会 | 每月1次 | 商户走访每周1次 |
