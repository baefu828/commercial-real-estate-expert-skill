# 商业地产租赁合同审阅要点

> 按业态分类的合同审阅检查清单，适配产业园、写字楼、商业街区、特色街区四种物业类型。

---

## 一、通用审阅十二维度

| 序号 | 维度 | 检查要点 | 风险等级 |
|------|------|---------|---------|
| 1 | 租赁面积 | 计租面积口径（建筑面积/套内面积/使用面积），公摊比例是否合理 | ★★★ |
| 2 | 租金条款 | 单价、递增机制（固定递增/复利递增）、支付周期（月付/季付/半年付） | ★★★★★ |
| 3 | 物业费 | 收费标准（含/不含公区能耗）、调价机制、服务内容边界 | ★★★★ |
| 4 | 保证金 | 金额（通常2-3个月租金+物业费）、退还条件、抵扣规则 | ★★★★★ |
| 5 | 免租期 | 天数、使用方式（集中/分段）、免租期间物业费承担 | ★★★ |
| 6 | 装修期 | 起止时间、装修标准、消防报审责任方 | ★★★ |
| 7 | 交付条件 | 交付标准（毛坯/简装/精装）、交付时间、延迟交付违约责任 | ★★★★ |
| 8 | 违约责任 | 提前解约罚则、逾期付款违约金、留置权条款 | ★★★★★ |
| 9 | 转租分租 | 是否允许、审批流程、转租收益分配 | ★★★ |
| 10 | 维修责任 | 主体结构 vs 内部设施的责任划分 | ★★★ |
| 11 | 合同期限 | 起租日、到期日、续租优先权、续租条件 | ★★★★ |
| 12 | 争议解决 | 管辖法院/仲裁机构、送达地址 | ★★ |

## 三、常见合同陷阱速查

| 陷阱类型 | 典型表现 | 应对策略 |
|---------|---------|---------|
| 面积陷阱 | 含无法使用的公摊面积计租 | 要求明确计租面积口径，附平面图 |
| 递增陷阱 | 复利递增逐年叠加 | 争取固定递增或设定递增上限 |
| 保证金陷阱 | 退还条件苛刻、无限期扣留 | 明确退还时效（如：交房后30日内） |
| 单方解约权 | 业主有解约权但租户没有 | 互惠原则，双方权利对等 |
| 无限连带责任 | 个人承担无限连带担保 | 争取公司担保或有限担保 |

## 四、合同审核流程（内部）

```
收到合同草案 → 逐条对照本要点 → 标记风险项 → 提出修改建议 → 同步法务复核 → 定稿签署
```

## 六、0101PARK 租赁合同关键条款速查（制度原文）

> 基于「文三数字生活街区0101PARK租赁合同模板」（2023版），16条+2附件。

### 核心商务条款

| 条款 | 合同约定 | 运营提示 |
|------|---------|---------|
| 计租面积 | 按计租面积，不因重新测量调整费用 | 签约前核实面积，图纸为唯一依据 |
| 租金递增 | **每年递增5%** | 固定递增，非复利 |
| 支付方式 | 先付后用，每N个月为一个交租期，**到期前20日**支付下期 | 注意20日这个时间节点 |
| 免租期 | 装修免租期，但**因乙方原因提前解约则视为不享有** | 合同中须明确约定"返还要约" |
| 保证金 | 签约当日支付，期满30日内无息退还 | 合同期内不可抵充租金 |
| 逾期违约金 | **0.5‰/日**（即万分之五） | 另有条款写"万分之三"，以0.5‰为准 |
| 公用事业费 | 水费5元/吨，电费1.25元/度，预付充值 | 非电网直供，物业管理方代收 |
| 市场推广费 | 按年收取，**提前终止不退** | 注意这是沉没成本 |
| 装修保证金 | 另行缴纳（金额按合同约定），另收装修管理费+施工证工本费 | 可与运营中保证金分开管理 |

### 关键违约触发点

| 违约情形 | 合同后果 |
|---------|---------|
| 逾期付保证金超过5日 | 甲方可解约 |
| 逾期付租金/管理费**超过15日**或**累计超过3次** | 甲方可解约，停水停电 |
| 逾期进场交接超过7日 | 甲方可解约 |
| 交接后15日内未进场装修 / 装修期逾期超过7日 | 甲方可解约 |
| 未在约定开业日开业 | 甲方可解约 |
| 连续3日不营业 / 月累计5日不营业 | 甲方可解约 |
| 擅自变更经营品牌、项目或转租 | 甲方可解约 |
| 违反管理规约，15日内未纠正 | 甲方可解约 |
| 欠费期间**商铺内货物不得转移** | 甲方可采取必要措施制止 |

### 合同结构速查（16条）
1. 租赁商铺基本情况（位置/计租面积/商铺状况/公共部位）
2. 租赁用途及经营主体要求（品牌/项目锁定，变更需书面同意）
3. 租赁期限（交付日/装修期/开业日/计租日/到期）
4. 租金、综合管理费和其他费用（递增5%/先付后用/水5电1.25）
5. 租赁保证金（签约日付/30日退还/不可抵充）
6. 进场装修要求（15日内交图纸/二次消防由乙方负责）
7. 日常管理（服从管理公司/保险/紧急状态/统一营业时间）
8. 甲方权利义务（主体结构维修/可委托管理公司行使权利/可转让）
9. 乙方权利义务（按时交租/合法经营/不可转租/收银系统/配合促销）
10. 合同终止解除（协商终止/甲方单方解约触发条件）
11. 商铺交还（5日内交还/1.5倍租金占用费/遗留物视为放弃）
12. 违约责任（逾期违约金0.5‰/日/损失赔偿）
13. 禁止商业贿赂
14. 通知（EMS送达视为送达）
15. 适用法律和争议解决
16. 其他（补充协议同等效力）

### 商户进场通知书关键节点
- 审核周期：提交资料后**7个工作日内**完成审核
- 进场时间调整：需提前**5个工作日**书面告知
- 开业延期：需提前**3个工作日**书面申请
- 费用前置：未缴清首期费用**不予办理进场**

### 装修期消防安全责任书16条核心要点
1. 施工人员提前2天报备名单+身份证
2. 严禁明火/煮食/吸烟
3. 动火须提前申请+预防保护措施
4. 严禁储存易燃易爆物品（确需须限量+专人看管）
5. 电气安装须持证电工操作
6. 施工材料须符合消防规范+防火检测报告备案
7. 每50㎡≥2具灭火器，人员须熟练使用
8. 严禁阻塞通道
9. 垃圾日产日清
10. 严禁挪用消防设备
11. 严禁移动/阻碍/掩盖消防设备
12. 每日收工后切断所有电源/气源，确认无火种
13. 甲方有权随时检查，不合格者停工离场
14. 施工人员禁到非工作区域闲逛/留宿
15. 特殊情况甲方有权检查携带物品
16. 施工事故由施工方负全责
