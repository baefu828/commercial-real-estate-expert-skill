### 西溪湿地物业租金收缴管理办法（2024.08）

| 时间节点 | 动作 | 责任部门 |
|---------|------|---------|
| 到期前1个月第3周 | 编制 **应收费用统计表**，与财务核对，报分管领导确认 | 物业管理部/财务部 |
| 到期前10天 | 发出 **《缴费通知书》**，跟踪缴纳情况 | 各区域负责人 |

| 逾期超30天 | 第二次催缴函，分管领导约谈企业商户负责人 | 客户服务部、招商运营部 |
| 逾期超45天 | **停止物业服务**，上报集团，启动法律程序 | 综合部、客户服务部 |

### 西溪湿地催缴处罚机制

| 阶段 | 措施 | 时限 |
|------|------|------|
| 逾期7日内 | 发出《催缴函》督促限期缴费 | 7日内 |

### 超保商户管理机制（0101PARK制度）

**触发条件（满足其一即触发解约机制）：**
- 保证金 < 3个月租金+物业费，且权责欠费达保证金50%
- 欠费达1.5个月租金+物业费（合同无特殊约定时）

**流程：**
营运部牵头梳理欠缴金额/周期/保证金/解约条件 → 会议反馈决策 → 确定解约 → 起草解约协议+会议纪要提交审批 → 早于撤场日完成审批

## 一、催缴分级策略总览

| 级别 | 逾期天数 | 措施 | 责任人 | 工具/产出 |
|------|---------|------|--------|---------|
| L0 预警 | 到期前7天 | 缴费提醒（系统推送/短信） | 运营专员 | 系统自动提醒 |
| L1 温和 | 逾期1-7天 | 电话/微信提醒，确认回款时间 | 运营专员 | 催缴话术模板 |
| L2 正式 | 逾期8-15天 | 发送正式催缴函（盖章） | 运营经理 | 催缴函模板 |
| L3 严厉 | 逾期16-30天 | 上门拜访+第二封催缴函，告知违约后果 | 运营经理+招商 | 面谈记录表 |
| L4 警告 | 逾期31-60天 | 律师函 | 法务/外聘律师 | 律师函 |
| L5 强制 | 逾期61-90天 | 停水停电/锁门（依合同约定） | 物业+运营 | 停供通知 |
| L6 诉讼 | 逾期90天+ | 提起诉讼/申请仲裁 | 法务+外聘律师 | 起诉状/仲裁申请 |
| L7 执行 | 判决后 | 申请强制执行、列入失信名单 | 法务+外聘律师 | 执行申请书 |

## 二、各阶段详细操作指引

### L0-L1：预警与温和催缴
- **操作频率**：到期前7天发提醒，到期后每3天联系一次
- **沟通要点**：先了解原因（现金流/经营困难/有纠纷），不是上来就施压
- **记录要求**：每次沟通记录时间、对象、承诺回款时间、实际理由

### L2-L3：正式函件阶段
- **催缴函关键要素**：
  - 欠缴金额明细（含滞纳金计算公式）
  - 最后缴款期限（通常给7-10天）
  - 逾期不缴的后果（计收违约金/解除合同/诉讼）
  - 盖章、签收记录
- **上门拜访要点**：带运营+招商2人同行，准备好欠款明细+催缴函，当面送达并拍照留存

### L4：律师函阶段
- **律师函效力**：虽然本身无强制执行效力，但能形成威慑，也是后续诉讼的前置程序
- **成本**：通常500-2000元/封（视律所而定）
- **发送方式**：EMS快递，保留快递单号和签收记录

### L5：强制措施阶段
- ⚠️ **前提**：合同中必须有明确约定"逾期付款超过X天，出租人有权采取停水停电措施"
- ⚠️ **程序要求**：提前3天书面通知，避免被认定为擅自断电造成经营损失
- ⚠️ **风险提示**：某些法院可能认定停水停电构成"自力救济过度"，请咨询专业律师

### L6-L7：诉讼与执行阶段
- **诉前准备**：租赁合同原件、催缴函+律师函送达记录、欠款明细表、沟通记录
- **诉讼策略选择**：
  - 小额诉讼（欠款 < 当地标准）：程序快，一审终审
  - 普通诉讼：全面解决，可同时主张解除合同+腾退房屋
  - 支付令：争议不大的情况下，比诉讼更快捷
- **执行难点**：租户名下无可供执行财产 → 需提前做信用评估和资产摸底

## 三、沟通话术模板

### 首次催缴（微信/电话）
```
[称呼]总/老板，您好。注意到[项目名][房号]的[月份]租金/物业费已到期，合计[金额]元。
想跟您确认一下，大概什么时间可以安排？如果有什么困难也可以跟我说，我们一起想办法。
```

### 二次跟进
```
[称呼]老板，上次跟您提到的[月份]费用还没收到。如果本周五前能安排的话，
滞纳金这块我可以帮您申请减免一部分。您看方便吗？
```

### 最后通牒
```
[称呼]老板，关于[房号]的欠费问题，我们已经多次沟通。
截至今天，欠缴金额共计[金额]元（含滞纳金）。按照合同约定，
如果[最后期限]前仍未缴清，我们将不得不启动正式法律程序。
这不是我们想看到的结果，希望您再认真考虑一下。
```

| 维度 | 指标 | 权重 | 评分标准 |

| 外部信息 | 企查查等平台的异常信息 | 15% | 无异常/少量诉讼/大量诉讼/被执行 |

## 六、风险预警机制

### 早期预警信号（发现以下信号，立即启动关注）
1. 连续2个月延迟付款（即使最终付了）
2. 企业负责人长时间联系不上
3. 店铺/办公室人员明显减少
4. 企查查出现新的涉诉信息
5. 员工私下透露"工资发不出来"
6. 突然要求调小面积或降租

### 响应机制
- 发现1-2个信号 → 运营经理重点关注，每月回访
- 发现3-4个信号 → 启动风险预案，评估保证金是否足够覆盖
- 发现5-6个信号 → 立即评估提前解约可行性

### 西溪湿地处罚标准速查

| 违规情形 | 处罚 |
|---------|------|
| 每次被开具《整改单》 | 扣保证金 500元 |
| 累计《整改单》达8次 | **单方解除租赁关系** |
| 消防安全未整改（首次） | 扣保证金 2000元 |
| 消防安全未整改（第二次） | 追加扣 5000元 |
| 消防安全未整改（第三次） | **终止合同**，取消租赁资格 |
| 拖欠费用1个月+ | **暂停10项物业服务** |

### 西溪湿地暂停物业服务范围（10项）
审批报批程序（含装修申请）、各类证照办理、房屋修缮、车辆通行证办理、水电设施维修、对外宣传、园区活动参与、工号牌制作、物品出门证开具、公司协调事项

### 费用缴纳管理制度（V1制度原文）
- **首期费用**：保证金+首期租金+物业费，招商催收完毕后移交运营备案
- **固定租金**：合同约定缴款周期，"先付后用"
- **扣点租金**：每月5日前商户提交上月营业额报表，按合同约定收取扣点
- **商户须如实提供每日营业额数据**
