# 商户星级评定体系

> 基于「杭州文三数字生活街区运营管理有限公司商户星级评定奖励办法」（2025年5月12日施行）。
> 这是 0101PARK 的实际运营制度，可直接参照使用。

---

## 一、评定总则

| 维度 | 内容 |
|------|------|
| 适用范围 | 0101PARK 内所有租赁商户（零售、餐饮、娱乐等） |
| 评定周期 | **每年一次**，提前1个月通知商户 |
| 评定小组 | 总经理室牵头，综合部+工程物业部+招商运营部+品牌宣传部组成 |
| 工作机制 | 联席会议制度，负责资料审核、实地考察、评分汇总、动态管理 |

---

## 二、评分标准（满分100分）

### 权重分配

| 维度 | 分数 | 权重 |
|------|------|------|
| 经营业绩 | 15分 | 营业额增长率10 + 坪效达成率5 |
| 服务质量 | 10分 | 投诉满意度3 + 员工服务4 + 环境卫生3 |
| 品牌形象 | 10分 | 品牌推广5 + 营销活动效果5 |
| **合规经营** | **55分** | 制度遵守20 + **费用缴纳及时性35** |
| 合作配合度 | 10分 | 参与街区活动次数 |
| **合计** | **100分** | |

> 💡 **关键发现**：合规经营占55分，其中费用缴纳占35分。这说明制度的底层逻辑是「按时缴费比经营好更重要」，招商运营人员在跟商户沟通时可以用这个逻辑说服商户。

### 各维度详细评分

#### 1. 经营业绩（15分）

| 指标 | 评分区间 |
|------|---------|
| 营业额增长率 | 0%以下=0分，0-5%=0-3分，5-10%=3-6分，10-20%=6-9分，20%以上=9-10分 |
| 坪效达成率 | 0-60%=0分，60-80%=1分，80-100%=3分，100-120%=4分，120%以上=5分 |

#### 2. 服务质量（10分）

| 指标 | 分值 | 评分方式 |
|------|------|---------|
| 投诉满意度 | 3分 | 无投诉=满分，每条有效投诉扣0.5分（政府/客服电话/微信等渠道） |
| 员工服务态度和专业 | 4分 | 现场考评：热情度(0-2分)、礼貌用语(0-1分)、业务知识(0-1分) |
| 环境卫生和商品陈列 | 3分 | 每张整改单扣0.5分 |

#### 3. 品牌形象（10分）

| 指标 | 分值 | 考核内容 |
|------|------|---------|
| 平台开通与基础信息 | 1分 | 至少1个平台（大众点评/美团/抖音/小红书）信息完整 |
| 定期文案宣推 | 1.5分 | 每年≥6篇推文，少1篇扣0.25分 |
| 评论互动 | 1.5分 | 最近50条评论答复率≥80%满分，每降10%扣0.25分 |
| 加分项 | — | 区级以上官方榜单排名前十（如大众点评必吃榜），直接满分 |
| 营销活动 | 5分 | 每年≥6次自办活动满分，少1次扣0.5分 |

#### 4. 合规经营（55分）

| 指标 | 分值 | 考核方式 |
|------|------|---------|
| 遵守规章制度 | 20分 | 日常巡查+抽查记录，每次违规扣0.5分 |
| **费用缴纳及时性** | **35分** | **每逾期1天扣0.5分**，无逾期=满分 |

#### 5. 合作配合度（10分）

| 参与频率 | 得分 |
|---------|------|
| 未参与 | 0分 |
| 1-3次 | 3分 |
| 4-6次 | 6分 |
| 7-9次 | 9分 |
| 10次以上 | 10分 |

## 三、星级设置

| 星级 | 分数段 | 定位 |
|------|--------|------|
| ⭐⭐⭐⭐⭐ 五星 | ≥90分 | 标杆商户，各方面表现卓越 |
| ⭐⭐⭐⭐ 四星 | 80-89分 | 经营良好，服务优质，合作度高 |
| ⭐⭐⭐ 三星 | 70-79分 | 达到平均水平以上 |
| ⭐⭐ 二星 | 60-69分 | 基本合格 |
| ⭐ 一星 | <60分 | **不合格**，次年不享受街区福利补贴（含区商务局2元租金补贴+活动补贴） |

## 四、奖惩措施

### 租金优惠（仅TOP 6）

| 排名 | 年度租金减免 |
|------|------------|
| TOP 1-2 | **减免3万元** |
| TOP 3-4 | **减免2万元** |
| TOP 5-6 | **减免1万元** |

### 资源推广

| 权益 | 内容 |
|------|------|
| 平台优先展示 | 街区公众号、小红书等线上平台优先展示 |
| 广告位优先 | 0101PARK 内外广告位优先租赁选择权 |
| 活动优先参与 | 主题促销、文化节等优先参与 |
| 荣誉牌匾 | 特制授牌悬挂于店铺显眼位置 |
| 培训机会 | 优先获得公司定期培训名额 |

### 惩罚措施

| 情形 | 处理 |
|------|------|
| 经营数据弄虚作假 | **取消星级资格+追回奖励** |
| 年度得分<60分（一星） | 次年**不再享受**街区各项福利补贴政策 |
| 奖励动态调整 | 运营情况变化可调整，调整前提前通知 |

## 六、运营应用建议

1. **签约时可预告知**：商户入驻时即告知星级评定制度，强调「按时缴费=35分」的权重，从源头建立缴费意识
2. **季度预评**：不要等到年底才评，每季度做一次预评排名，让商户知道自己在什么位置
3. **低分商户帮扶**：对60-70分的商户，招商运营部应主动提供经营帮扶（活动参与、推广支持）
4. **激励杠杆**：3万元减免 vs 租金总额，需评估激励效果。若租金较高（如年租20万+），3万减免约等于打85折
